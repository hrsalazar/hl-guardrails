# Security

This tool is read-only: it holds no exchange keys and cannot place orders. Everything it publishes
is encrypted (AES-256-GCM), and its public logs are redacted.

The full model, including what is and isn't protected, the secrets inventory and rotation
procedures, is in [docs/security.md](docs/security.md).

To report a vulnerability, please don't open a public issue; see
[docs/security.md#reporting-a-vulnerability](docs/security.md#reporting-a-vulnerability).
